日常使用

1. 编辑同目录的「预约设置.ini」，填写场馆、打球日期、开始时间、结束时间和场地编号。
   账号和密码继续放在 config.ini，不需要反复修改。
2. 双击「预览设置.command」，核对完整条件和北京时间。
3. 双击「开始抢场.command」，保持该终端窗口开启，程序会等待放号。
   提前一分钟登录，到放号时间自动尝试；成功提交一单后结束。
   如已过放号时间，启动后立即尝试。
   weekdays 每周模式会继续等待后续打球日，直到你按 Control+C 停止。
4. 抢到后打开 https://epe.pku.edu.cn/venue/orders 核对订单。
   默认不自动付款；需要付款的订单请及时手动完成，以网页截止时间为准。
   0 元订单是否已完成，以预约记录显示的状态为准。

预约配置示例

[reservation]
venue = 五四体育中心-室外网球场
date = 2026-10-30
start_time = 06:00
end_time = 07:00
courts = 1

date 是打球日期，不是运行脚本的日期。
courts = 1 表示只约 1 号；courts = 1,2 表示只在 1、2 号之间按顺序选择。
完整时间段不可用时不会自动缩短，也不会改订未指定的场地。

[execution]
advance_days = 3
release_time = 12:00:00
auto_pay = false
attempts = 20
retry_interval = 1

上面的例子会在 10 月 27 日 11:59 登录，12:00 开始抢 10 月 30 日的场地。
放号规则默认是提前三天中午 12 点；如场馆调整规则，可修改 advance_days 和 release_time。
auto_pay = false 关闭自动付款。只有主动改为 true，才会尝试校园卡自动付款。
每轮验证码识别可能消耗题分；达到 attempts 轮仍没约到就结束，不无限刷场。
固定 date 模式只抢一次。每周模式按 weekdays 循环，每个打球日期成功一单后等待下一个日期。

每周模式（当前设置）

[reservation]
venue = 五四体育中心-室外网球场
date =
weekdays = 2,3,4,5
start_time = 10:00
end_time = 12:00
courts = 2,3

[execution]
advance_days = 1
release_time = 12:00:00
auto_pay = false

weekdays 是实际打球的星期，1=周一，7=周日。
当前每周二、三、四、五打球；按提前一天放号，在周一到周四 11:59 登录，12:00 开始抢次日的场地。
每个打球日只约一个完整的 10:00–12:00：优先 2 号，2 号不可用才选 3 号，不会两个场地都约。
启动时若下一打球日已放号但还没开场，会立即尝试；已经开场或过去的日期会跳过。
当日成功、失败或已经提交过的任务会留下记录；重启不会反复重做同一天。随后继续等待下一日期。
若要重试已失败的一天，可先确认没有订单，再用固定 date 模式，并清空 weekdays；提交结果不明的记录仍会拦截重复下单。
要改为只抢一次：填 date = YYYY-MM-DD，并清空 weekdays。两项不能同时填写。
启动方式仍然是双击「开始抢场.command」，保持终端窗口运行。停止后下次需要重新启动，不会开机自动运行。

运行时
Mac 需保持开机、联网，建议接电且不要合盖。
启动入口会防止空闲睡眠；关闭终端、退出任务、关机或合盖睡眠会影响执行。
修改配置不会改变已经运行的任务；请先按 Control+C 停止，再重新启动。
要取消已经提交的预约，请在智慧场馆预约记录中处理，停止脚本不会取消订单。
程序会记录已提交任务并检查重复启动；下单响应异常时会停止，先核对订单再处理。
当前使用每周模式：date 留空，weekdays = 2,3,4,5；无须每周手动改日期。

终端入口
cd /你的路径/PKUAutoVenues-2026
./run.sh                        预览预约设置，不联网
./run.sh preview                同上
./run.sh start                  启动这一次实际预约，自动等待放号
./run.sh check                  检查账号和依赖
./run.sh check --login          仅测试登录，不预约
./run.sh check --captcha        测试一次超级鹰识别并校验，消耗题分，不预约
./run.sh --help                 查看原命令行参数用法

本地文件
config.ini：北大和验证码平台账号，已被 Git 忽略，权限仅当前用户可读写。
预约设置.ini：日常预约条件，已被 Git 忽略，不包含账号密码。
.state/：本地提交记录与任务锁，已被 Git 忽略。
logs/：运行日志、验证码测试及此前一次预约结果，已被 Git 忽略。
Python 3.12 和依赖保存在项目独立环境；没有改动系统 Python 或 shell 配置。
没有注册开机自启或系统定时任务；每次修改后双击「开始抢场」即可开始等待。
